# Murkuz

Remote MCP server: https://murkuz.com/mcp (sign in with OAuth when Cursor asks).

Tools: My_Sites, Search_Analytics, Live_Quick_Wins, Live_Content_Decay, Analyze_Page, SEO_Score, Apply_SEO_Fix, Read_Article, Write_Article, Edit_Article.

## How to use

1. Start with My_Sites to pick the site, then Search_Analytics or Live_Quick_Wins for data.
2. Audit a URL with Analyze_Page or SEO_Score before suggesting changes.
3. Read_Article before Edit_Article; confirm with the user before Apply_SEO_Fix or publishing.
4. Report numbers exactly as returned.
